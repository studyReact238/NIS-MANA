# Preview Project

This workflow starts the local development server for the Next.js app to preview it locally.

1. Ensure you are in the correct directory.
   ```bash
   cd c:\Users\maske\Downloads\NIS-MANA
   ```

2. Start the local development server.
   // turbo
   ```bash
   cmd.exe /c "npm run dev"
   ```

3. Open a browser and navigate to the local URL (usually http://localhost:9002 or as designated by your terminal output).
