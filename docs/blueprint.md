# **App Name**: LinkFlow

## Core Features:

- User Authentication: Dummy user authentication using localStorage for demonstration purposes, with visual indicators for administrator access.
- Link Dashboard: Comprehensive dashboard for displaying learning links, featuring robust search by title, description, and tags, multi-filter options by status (all, in progress, completed), tags, custom colors, and icons, plus sorting capabilities by title or last updated date.
- Link Management (CRUD): Enable full lifecycle management of learning links, including creation, viewing, editing, duplication, and deletion, controlled by an admin toggle. Completed links are visually marked with desaturated colors and a checkmark.
- AI Link Summarizer Tool: Utilize AI to fetch content from a given URL and generate a concise summary of the webpage in Japanese.
- AI Tag Suggester Tool: Leverage AI to analyze the content of a webpage and suggest relevant tags for better organization.
- Link Customization: Allow users to customize the visual appearance of each link by selecting from 5 predefined colors and 8 distinct icons (e.g., Book, Video, Globe).
- Tag Management: Provide a flexible interface for managing tags, supporting both manual input (with 'Add' button and Enter key guidance) and one-click selection from a list of existing tags.

## Style Guidelines:

- Primary color: Emerald green (#1FAD4E), chosen for its vibrant and clean feel, reflecting clarity and vitality.
- Background color: A very light greenish-gray (#F0F4F2), providing a serene and spacious canvas while subtly harmonizing with the primary emerald.
- Accent color: A bright yellow-green (#E0F76E), providing a contrasting yet analogous pop of color for interactive elements and highlights, bringing liveliness.
- Headline font: 'Space Grotesk' (sans-serif) for all headings, providing a modern and tech-infused aesthetic.
- Body font: 'Inter' (sans-serif) for all body text, ensuring high readability and a clean, objective feel for content.
- Implement a consistent set of illustrative icons for link types (e.g., Book, Video, Globe) and filtering options to enhance visual identification.
- Utilize large rounded corners (e.g., rounded-[2.5rem] or 3xl), deep shadows (shadow-xl), background gradients, and glassmorphism (backdrop-blur) for a distinctive, modern, and lively user interface.
