# 「にすまな」基本設計書（外部設計書）

## 1. システム概要
「スキマ時間でちょいアプデ。」をコンセプトに、組織内のナレッジ共有を活性化させるマイクロラーニング・プラットフォーム。管理者による良質なリンク共有と、ユーザーによる学習進捗・評価の可視化を核とする。

---

## 2. 画面一覧
| 画面ID | 画面名 | 概要 | アクセス権限 |
| :--- | :--- | :--- | :--- |
| G01 | ログイン画面 | メールアドレス・パスワードによる認証 | 未認証ユーザー |
| G02 | ダッシュボード | リンク一覧、進捗サマリー、タイムライン | 全ユーザー |
| G03 | リンク詳細 | リンクの概要説明、統計情報、学習者リスト | 全ユーザー |
| G04 | リンク登録・編集 | リソースの新規作成および内容の変更 | 管理者 / 投稿者 |
| G05 | ユーザー・システム管理 | ユーザー登録、権限付与、統計再集計 | 管理者 |
| G06 | 確認テストビューアー | アップロードされたHTMLテストの実行 | 全ユーザー（受講済み限定） |

## 3. 各画面詳細仕様

### [G01] ログイン画面
#### 3.1 機能概要
- Firebase Authenticationを利用した、セキュアなID/PW認証。

#### 3.2 UI項目・バリデーション
- **メールアドレス**: 必須入力。正しいメール形式であること。
- **パスワード**: 必須入力。
- **ログインボタン**: 認証成功時にダッシュボードへ遷移。失敗時にトーストでエラー通知。

---

### [G02] ダッシュボード（メイン画面）
#### 3.1 機能概要
- ラーニングリソースの検索、フィルタリング、並べ替え。
- 自身の全体進捗状況のリアルタイム表示。

#### 3.2 UI項目
- **進捗サマリー**: 「未着手」「学習中」「受講済み」の数をプログレスバーで可視化。
- **検索バー**: タイトル、説明、タグに対する部分一致検索（クライアントサイド）。
- **ステータスフィルター**: タブ形式による受講状況の絞り込み。
- **推奨フィルター**: 推奨/非推奨コンテンツの切り替え。
- **詳細絞り込み（折りたたみ）**:
    - **カラー/アイコン**: UIテーマによる視覚的な絞り込み。
    - **タグ**: 登録済みタグのマルチセレクト。
- **リンクカード**: 各教材のサマリーを表示。

#### 3.3 並べ替えロジック
- 更新日時（新着/古い順）、タイトル（昇順/降順）、評価（高評価数-低評価数）、学習中人数。

---

### [G03] リンク詳細ダイアログ
#### 3.1 機能概要
- 教材の完全な説明文、統計情報の詳細表示。
- 管理者のみ、当該教材を現在学習している、または完了したユーザーの実名リストを確認可能。

#### 3.2 推奨ロジック (Recommendation Engine)
- **推奨コンテンツ判定**:
    1. `高評価数 >= (全ユーザー数 * 0.1)` (10%以上のユーザーが評価)
    2. かつ `高評価数 > 低評価数`
- 条件を満たす場合、`Sparkles`アイコンと共に推奨バッジが付与される。

---

### [G04] リンク登録・編集ダイアログ
#### 3.1 機能概要
- 学習リソースのメタデータ管理。

#### 3.2 UI項目
- **確認テスト設定**: 
    - URL指定：Googleフォーム等の外部ツールを指定。
    - HTMLアップロード：自作のテストHTMLファイルを直接ホスティング（Sandbox化されたiframeで実行）。
- **タグ管理**: 既存タグの候補表示および新規タグの動的追加。
- **テーマ設定**: カラー5色 × アイコン8種から選択。

---

### [G05] ユーザー・システム管理ダイアログ（管理者専用）
#### 3.1 ユーザー管理機能
- **新規登録**: 姓名（姓・名）、メール、パスワードを指定してユーザーを新規作成。
- **権限管理**: 管理者権限（盾マーク）の付与・剥奪。
- **プロフィール編集**: 登録済みユーザーの姓名を後から変更可能。
- **進捗監視**: 特定ユーザーが現在どの教材を学習中か、完了したかを一覧表示。

#### 3.2 システムメンテナンス機能
- **統計情報の同期**: 各教材の「学習中/完了」のカウント値が実データと乖離した場合、全ユーザーのドキュメントを再スキャンしてカウントをバッチ修正する。

---

### [G06] 確認テストビューアー
#### 3.1 機能概要
- 教材を「受講済み」にしたユーザーのみがアクセス可能。
- 直接アップロードされたHTMLを `srcDoc` として展開し、セキュアな環境でテストを実行。

---

## 4. 共通仕様・非機能要件

### 4.1 リアルタイム同期
- Firestoreの `onSnapshot` を活用。他ユーザーが学習を開始したり、管理者が情報を更新したりすると、リロードなしで即座にUIが反映される。

### 4.2 セキュリティ設計 (Firebase Security Rules)
- **認証**: 全ての読み書きは認証済みユーザーに限定。
- **管理者権限**: `/admins/{userId}` ドキュメントの存在により、書き込み権限を動的に制御。
- **所有権**: 各ユーザーの進捗データ（`/users/{userId}/progress`）は本人以外書き込み不可。

### 4.3 パフォーマンス最適化
- **Memoization**: `useMemoFirebase` などのカスタムフックにより、Firestoreのリファレンス再生成による無限ループを防止。
- **Static Export**: Next.jsの `output: 'export'` モードにより、Firebase Hosting上で高速な静的配信を実現。
